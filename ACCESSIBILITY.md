# Accessibility

CampusBite is a browser-based application intended to be used on desktop and
mobile devices. The project does not currently publish a formal browser support
matrix or claim conformance with a particular accessibility standard.

No comprehensive accessibility audit has been completed, so known barriers have
not yet been fully assessed. We welcome reports about barriers involving
keyboard use, screen readers, contrast, text sizing, or other access needs.

To report an accessibility issue, open a GitHub issue in this repository. Please
include the page or workflow, the browser and assistive technology (if
applicable), what you were trying to do, and what happened. Do not include
personal or sensitive information. The project will use reports to guide
improvements and will update this statement as its support and testing evolve.
