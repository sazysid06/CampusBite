# Security Policy

## Supported versions

Security reports are currently accepted for the latest version on the default
branch. This project does not publish a separate supported-version schedule.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/sazysid06/CampusBite/security/advisories/new)
if it is enabled for this repository. If private reporting is unavailable,
contact the maintainer through [GitHub](https://github.com/sazysid06) rather
than opening a public issue.

Include a description of the affected component, the impact, and steps to
reproduce the issue. Do not include real user data, credentials, or other
sensitive information in a report.

Please allow maintainers time to investigate before making a vulnerability
public. There is no guaranteed response or remediation time at this stage.

## Scope

Reports are most useful when they demonstrate a security impact in the CampusBite
application or its repository configuration. Do not test against systems or
accounts that you do not own or have permission to use.
